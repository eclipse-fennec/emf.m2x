Fennec OCL — Eclipse Update Site

__BRANCH__

This is a p2 update site that delivers Fennec OCL support for the Eclipse EMF Generic Editor — OCL delegate support (validation, derived features and invocation) for models opened in the generic reflective editor. It is not a normal web page; install it into your Eclipse IDE using the URL below.

__P2_URL__

Install in Eclipse

  1. In Eclipse, open Help → Install New Software…
  2. Click Add…, paste the URL above into the Location field, and confirm.
  3. Select the Fennec OCL feature, click Next, accept the EPL-2.0 license, and finish.
  4. Restart Eclipse when prompted.
Browsing this folder shows the repository metadata (content.jar, artifacts.jar, p2.index). Eclipse reads those files automatically — you do not need to download anything by hand.
